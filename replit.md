# Mundo da Poupança — Aventura Financeira

Educational HTML5 Canvas game teaching compound interest and stock market basics, designed as a 6th-grade math school project.

## How to run

The workflow **"Start application"** serves the game via a native Node.js static file server (`server.js`) on port 5000. No build step or npm install needed.

```bash
node server.js
```

## Stack

- Pure HTML5 Canvas + vanilla JavaScript (no frameworks, no build tools)
- CSS in `css/style.css`
- Game logic split across `js/` modules (see README.md for full breakdown)
- Progress saved in browser `localStorage`
